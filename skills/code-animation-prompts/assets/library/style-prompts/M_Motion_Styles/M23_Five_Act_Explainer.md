# M23 Five-Act Explainer (Universal Explainer Template)

- Category: M Motion Styles · Explainer
- What it looks like: Five shots to explain one thing.
- Good for: The skeleton of a science episode, or a passage about a tool on the feeling line.

## Style Prompt

You are a senior motion designer. Use one HTML page to make a [30]-second explainer animation in 5 acts: 1) the problem the viewer runs into; 2) what [the thing] is; 3) how to use it, in 3 steps; 4) a real example; 5) an end card with [channel name]. Big bold type, smooth transitions, our color palette.

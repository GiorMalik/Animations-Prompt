## Style Prompt

High-end minimalism. One shot, one idea; lots of empty space, a single accent color, tight-tracked sans-serif type revealed through masks, a steady camera. Every cut lands on the downbeat; every interface move hits the beat. No periods on on-screen text. No shockwaves, particles, RGB split, shake, glow, neon, flicker, or bouncy easing. Only music and sound effects cleared for commercial use.

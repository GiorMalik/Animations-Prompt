# M6 Apple Keynote Style

- Category: M Motion Styles · Pacing & Fast Cuts
- What it looks like: Soft, white, bright blue, glassy textures; the camera never cuts on a still frame.
- Good for: Passages that show off a tool or an interface.

## Style Prompt

The feel of an Apple keynote: soft, white, bright blue, glassy textures. Never cut on a still frame — every shot is already moving when it enters, and speeds up or carries motion blur as it leaves. Inter for the type. No purple, magenta, or orange.

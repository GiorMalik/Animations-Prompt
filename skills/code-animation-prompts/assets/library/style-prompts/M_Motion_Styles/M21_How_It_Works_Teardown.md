# M21 How It Works: A Teardown

- Category: M Motion Styles · Explainer
- What it looks like: Take something apart and show, step by step, how it works inside.
- Good for: The announcement-grabbing example (schedule, fetch, filter, summarize, remind), explaining "how exactly does it do that?"

## Style Prompt

Make a motion graphic that explains clearly how [a thing] works. Break the process into [3 to 5] steps, one shot per step; the result of each step becomes the start of the next, and at the end show the whole picture together.

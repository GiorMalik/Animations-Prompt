# M11 Life Loop

- Category: M Motion Styles · Mood & Atmosphere (most used on the feeling line)
- What it looks like: The same person, from childhood to old age, finally looping seamlessly back to the start.
- Good for: Passages about long stretches of time, like "learning never ends" or "always learning".

## Style Prompt

Make a [20]-second animation: the same person goes from [stage 1] to [stage 2] to [stage 3]… and finally loops seamlessly back to the start.

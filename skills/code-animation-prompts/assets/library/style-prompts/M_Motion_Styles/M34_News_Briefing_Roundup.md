# M34 News Briefing Roundup

- Category: M Motion Styles · Pacing & Fast Cuts
- What it looks like: Like a news show: item by item, each one pointing out what's interesting.
- Good for: For future roundups like "what's new in AI this week".

## Style Prompt

Make a roughly 60-second motion graphic, good-looking and easy to follow, that presents what's new in [field] during [time period] like a news briefing, explaining from an ordinary user's point of view what's interesting about each item.

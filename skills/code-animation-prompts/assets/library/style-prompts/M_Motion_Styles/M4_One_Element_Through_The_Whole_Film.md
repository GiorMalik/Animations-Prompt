# M4 One Element Through the Whole Film

- Category: M Motion Styles · Structure & Camera (for stitching styles together)
- What it looks like: One small thing (an orange dot, a white ball) runs through every scene: first it is a switch, then the dot on a letter, then a curve, then a shape, and finally it returns at the end.
- Good for: The "thread" when mixing styles. For example, a small dot can stand for "an announcement" or "an idea", following it from start to finish.

## Style Prompt

A small [color] dot threads through every scene: [what it is in scene 1], then it becomes [what it is in scene 2]… and finally returns to the end card. The dot can never teleport — it must travel there continuously. The motion is crisp and clean, with very little spring bounce and no dead air. No stock video, no gradients, no glow, no particle explosions, no random transitions. The last frame is the same as the first, so it can loop.

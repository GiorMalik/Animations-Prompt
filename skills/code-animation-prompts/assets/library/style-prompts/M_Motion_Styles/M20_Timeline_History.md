# M20 Timeline / History

- Category: M Motion Styles · Explainer
- What it looks like: A timeline moves forward, and at each node an event pops up.
- Good for: "How I got through these three months", "how AI got to where it is today".

## Style Prompt

Make a timeline animation about a few key moments between [when] and [when]: [moment 1, moment 2, moment 3]. The timeline advances left to right; at each node, zoom in to tell that one story, then zoom back out and keep going.

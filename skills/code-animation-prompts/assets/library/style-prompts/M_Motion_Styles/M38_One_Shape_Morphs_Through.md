# M38 One Shape Morphs All the Way Through

- Category: M Motion Styles · Structure & Camera (for stitching styles together)
- What it looks like: One shape keeps changing: a button, a loading spinner, a player, a slider, a switch… and every change is triggered by a real mouse click.
- Good for: Passages that list many examples in one breath, like "tidying spreadsheets, writing weekly reports, batch-renaming files, running a channel".

## Style Prompt

One shape, no cuts from start to finish, turning in turn into [example 1, example 2, example 3…]; what changes is size, corner radius, and color. Every change is triggered by a real mouse click or drag. Springs everywhere, with at most a tiny bit of bounce. The camera zooms in to follow, so each state fills the frame. The last frame is the same as the first.

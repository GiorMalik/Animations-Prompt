# M19 Beginner-Friendly Science

- Category: M Motion Styles · Explainer
- What it looks like: Any visual style works; what matters is the approach: start from an everyday example and build up to the technical term step by step.
- Good for: A whole episode on the science-explainer line, or the "first, let's get clear on what X is" passage on the feeling line.

## Style Prompt

Make a video about [a topic] that goes deep but stays simple, so someone with no background at all can follow it. Open with an everyday example, then introduce the technical terms. Include voiceover, spoken in Chinese. Install whatever tools you need; look things up online.

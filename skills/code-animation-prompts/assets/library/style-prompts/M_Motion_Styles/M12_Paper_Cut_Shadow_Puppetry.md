# M12 Paper-Cut Shadow Puppetry

- Category: M Motion Styles · Mood & Atmosphere (most used on the feeling line)
- What it looks like: Paper-cut silhouettes performing behind the light, with soft sounds.
- Good for: Passages about "home", memories, warmth. Works well in vertical video.

## Style Prompt

Using pure JavaScript, make a [30 to 60]-second vertical 9:16 animation in the style of paper-cut shadow puppetry. Add soft, fitting sounds — the sounds are made with code too. The theme: [a question, for example "What turns a place into a home"].

# M22 Recipe-Style Steps

- Category: M Motion Styles · Explainer
- What it looks like: Like a cocktail tutorial: start from an empty glass, and every time something goes in, label its name and amount, until the finished drink.
- Good for: Teaching passages like "you only need these steps to build a small tool".

## Style Prompt

In the style of an explainer video, go step by step from [starting point] to [finished product]. Every time something is added, label on screen what it is and how much. [N] seconds.
